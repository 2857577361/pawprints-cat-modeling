## 方法与重现

这是本地离线的“照片投射 + 照片毛色片段采样 + 手工补绘”的混合方案，不是自动照片三维重建，也不是完整 Blender Projection Paint。当前电脑没有 Blender，本轮没有生成 .blend 工程。

```sh
python3 scripts/bake-cat-coats.py \
  --reference-dir /本地照片文件夹 \
  --audit-dir /本地输出检查文件夹
npm run dev
```

需要 Python、numpy、Pillow。参考目录按本轮用户上传顺序命名 01.jpg … 12.jpg；照片不会联网传输。

开发时打开 `http://127.0.0.1:5188/coat-review.html`，提供两只猫、正脸、左右 45°、侧面、背部、尾巴、脚爪、原版/新版花色切换，以及走路/奔跑/跳跃预览。原版切换只比较花色材质，不会撤销这轮几何调整。

照片、注册参数和生成代码是三种独立输入。换一只猫不能仅替换照片文件：必须重新标定脸部坐标、采样区域及花斑范围，否则会错位。

## 当前边界 / 下一轮重点

本轮是可运行的第一轮相似度改进，不能声称已达到照片级还原或已经通过用户的相似度验收。

- 照片不是校色拍摄，仍有环境色和阴影；亮度校正只是近似去光影，不是真正测量得到的 albedo。
- 正面花纹有照片依据，但侧脸、耳背和部分腹部缺少完整匹配视角，仍有平滑补色；羊羊后脑/臀斑边界是参考照片手工拟合。
- 薯片尾部目前主要还原整体灰度及蓬松度，没有逐圈复刻全部尾纹。
- 基础网格仍为共同资产，颅骨、侧脸、耳根和嘴部没有完整雕刻重建，因此长相仍有差距。本条描述 0.3.1 状态；0.3.2 已改用源空间眼球坐标驱动的虹膜材质，见 FACE-REWORK-0.3.2.md。
- 2K UV 图中脸部占用面积有限，极近距离仍会模糊；进一步提升需要更高脸部纹素密度及更准确投射标定。
- 未计算声称客观相似度的评分；未提供把不同光照下 RGB 差当作真实毛色误差的表格。
