# 猫咪角色验收清单

复制到自己的角色目录后填写。未检查项保留未勾选；附上证据文件，而不是只写“通过”。本模板没有预先通过的项目。

## 静态相似度

- [ ] 正面脸型、眼距、耳形、口鼻符合参考；附照片与渲染对照。
- [ ] 左右侧面轮廓与身体比例合理；不确定区域已标记。
- [ ] 花斑左右、鼻梁白斑、胸毛、爪色、尾色没有镜像或串色。
- [ ] 中性灯光下毛色接近照片；未把光照偏色当成固有颜色。
- [ ] 放大后眼睑、鼻头、胡须与毛根可见，没有被长毛遮住。

- [ ] 虹膜清晰，瞳孔比例合理，眼球没有突出眼眶；眨眼时眼睑不悬空。
- [ ] 鼻革、鼻孔、人中与唇线连续，口鼻补片没有露缝、双重嘴线或明显接边。
- [ ] 耳壳和耳内颜色分离，耳根及颊毛轮廓与照片一致。

## 变形与动作

- [ ] 单独抬左/右后腿时，腹部、对侧腿与尾巴不被错误牵动。
- [ ] 走路、奔跑、跳跃及落地的后脚保持分离；膝与跗关节方向合理。
- [ ] 支撑脚不明显滑动；足端预测不超出腿长和关节可达范围。
- [ ] 连续急转弯、反向移动、停止及重新起步不会跨腿或拉出薄片。
- [ ] 尾巴各段有连续过渡和有限幅度；尾端没有突跳、抽搐或断裂。
- [ ] 毛发随皮肤稳定变形，花色不随世界坐标漂移。
- [ ] 骨骼独立，多个角色不会共享姿态或互相影响。

## 交付与性能

- [ ] 输出文件实际存在，独立查看器能加载、旋转、缩放、播放动作。
- [ ] 在第二个工具中打开导出资产，确认材质、蒙皮与动画保留。
- [ ] 若特效需要运行代码，交付了代码与依赖说明，不声称 GLB 已包含。
- [ ] 记录硬件、分辨率、近中远视角帧率、内存和资产大小。
- [ ] 没有照搬别的模型的骨名、UV 区域或坐标阈值。
- [ ] 作者、许可、素材来源和修改范围完整。
