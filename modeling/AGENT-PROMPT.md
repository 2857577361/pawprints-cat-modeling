# 直接交给 Agent 的建模任务

将下方文字复制给你使用的 Agent，并附上自己的猫咪照片。名字、生日、风格或目标引擎可以另外补充；缺少这些信息不应阻碍先检查照片和工具。

---

请依据我提供的猫咪照片，为我的猫制作可复用、可查看细节、可播放动作的三维角色。

先读取本仓库 `modeling/WORKFLOW.md`、`modeling/ACCEPTANCE.md`，并使用 `modeling/templates/` 的模板记录特征和资产适配。建模工作独立完成，不把上传、资料管理或建模入口接入《爪印》或其他 App。

请按以下顺序执行：

1. 检查可用工具和照片，确认照片方向，列出可确认的脸型、体型、花色、毛长、眼睛与尾巴特征。看不到的部位标记为推测。现有资料足够推进时先做，不反复询问已有信息。
2. 选择许可明确且解剖结构适合的基础资产，或使用可用工具重新建模。记录来源、作者、许可和修改。使用本仓库的猫模型时保留 ATTRIBUTION.md 中的双作者署名。
3. 先做无毛灰模和多角度对比，调整脸、耳、口鼻、体型与尾巴。随后制作独立的花色、眼睛、鼻头与脚垫。
4. 制作分区毛流和毛发，身体与毛发共享花色与蒙皮。优先保证像我的猫、轮廓正确，再提高面数与毛量。
5. 制作静止、走路、奔跑、跳跃。检查后腿没有粘连、膝盖没有反折，尾巴没有被腿部牵动，急转弯不会跨腿。正面、侧面、背面都要检查。
6. 交付可编辑工程或完整生成脚本、实际可用的运行资产、独立查看器、多角度预览和动作预览；写明依赖安装与启动步骤。默认目标是桌面实时展示，可旋转、缩放和切换动作。
7. 每轮保存关键参数、随机种子和对比结果，最后报告通过的检查、未完成项目和相似度不足的位置。

请遵守：

- 不把照片取色、套模型或程序化毛发称为真实照片扫描重建。
- 不把基础 GLB 冒充我的猫的成品模型；说明定制效果在导出文件中还是运行代码中。
- 不未经我的授权把照片上传到外部建模平台。若外部服务确实必要，先给出具体服务、要发送的照片和费用，再询问。
- 不为了截图好看而只交付平面图片；展示器应能转动观察同一个三维角色。
- 不虚构 `.blend`、GLB、动作片段、测试通过或“照片级”的完成情况。
- 如果当前工具做不到某一步，明确说明并完成其他可执行步骤，不把计划当成已经实现。

现在从检查照片与工具开始，并持续推进到有可查看、可复用的交付物。
